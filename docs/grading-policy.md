# Grading policy

- Credit is awarded criterion by criterion and may not exceed rubric maxima.
- Every criterion needs evidence traceable to the student answer or an allowed source excerpt.
- Alternative valid methods are acceptable unless a rubric criterion explicitly requires a
  method.
- Exact analyst/verifier point agreement is required for automatic approval.
- Confidence below the configured threshold (default `0.70`), any explicit assessor concern,
  or a disagreement between valid assessments requires human review.
- Missing/duplicate/unexpected criteria, invalid citations, or score-bound violations make an
  assessment invalid. They receive one fresh validation retry; repeated failure aborts the run
  without a new report rather than reconciling an invalid assessment.
- A human-review result has no final total and produces no student-facing feedback.
